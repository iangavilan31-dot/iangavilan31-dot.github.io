Rift Warden

A pixel arena roguelite with shifting waves, weapon choices, and a fight to survive.

the curiositythe buildthe practice

01 / the question behind it

Can an arena’s weapons and wave choices make each run develop its own character?

Rift Warden is a Phaser and TypeScript arena roguelite with enemy waves, weapons, upgrades and persistent progression. Its browser build combines generated environment and character art, animated sprite states and procedural audio.

02 / from idea to something playable

how the pieces came together.

  1. 01

    Build a run from scenes and data

    An armory and arena connect weapon identity to the playable run. Weapons such as the Ashblade define roles, tags and combat behavior rather than existing only as artwork.

  2. 02

    Give enemies and players explicit states

    The shipped art includes idle, walk, attack, hurt and death sprite strips. Keeping those states distinct helps the player read a crowded arena.

  3. 03

    Carry selected progress between runs

    The save data stores progression such as mastery, discoveries and rift depth. Upgrade choices and enemy waves give each new attempt room to develop differently.

03 / the skills in the work

what this helped me practice.

The project develops scene-based game architecture, upgrade data and sprite integration. Keeping combat readable across waves also exercises enemy-state design and the coordination of art, effects and interface.

  • Phaser
  • TypeScript
  • Upgrade systems
  • Sprite animation
  • Procedural audio

a note on the process.

Animation and combat rules need to be reviewed together. A polished still image cannot replace an attack that clearly announces when it begins and when it connects.
