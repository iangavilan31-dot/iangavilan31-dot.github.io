Sable Seas

A pirate sandbox across nine islands, with sailing, cannon battles, and room for a crew.

the curiositythe buildthe practice

01 / the question behind it

How much of a pirate adventure can come from a crew operating one shared ship?

Sable Seas is a first-person Three.js pirate sandbox with nine islands, wind-dependent sailing, cannon combat and browser co-op. Rendering, simulation, data, audio and networking are separate modules, with a host simulating shared world state.

02 / from idea to something playable

how the pieces came together.

  1. 01

    Make the ship a set of shared jobs

    The wheel, capstan, sails and cannons are usable stations with occupancy rules. Wind, rudder position and gradual acceleration connect those jobs to actual sailing.

  2. 02

    Connect the sea to a voyage

    Treasure charts lead to island digs; chests can be carried, stowed and sold back at the harbor. Damage creates hull holes, rising water and repairs, giving the return journey its own decisions.

  3. 03

    Keep one world for the crew

    Room codes and host-simulated shared state coordinate stations, actions and voyage votes. Guest interpolation smooths remote movement, while host-loss handling explains when the session has ended.

03 / the skills in the work

what this helped me practice.

The project develops procedural water, multiplayer state design and the integration of animated 3D assets. It also exercises research, asset adaptation and turning a collection of mechanics into a complete voyage.

  • Three.js
  • Ocean shaders
  • Browser networking
  • 3D asset integration
  • Simulation design

a note on the process.

Shared stations make cooperation concrete. The useful constraint is that a voyage must still make sense from lowering the sail to selling the recovered cargo.

where the project stands

Playable early browser build with invited-crew co-op; sustained separate-network testing and broader production work remain.
