Somnium

A painted, two-player journey through a dark fantasy world.

the curiositythe buildthe practice

01 / the question behind it

Can a quiet two-player journey use the same gesture for resting, helping and moving forward?

Somnium is a painted Canvas and TypeScript journey through five chapters and an epilogue. Procedurally baked scene layers, articulated knights and a shared camera connect exploration, encounters and campfire transitions.

02 / from idea to something playable

how the pieces came together.

  1. 01

    Author the journey as connected scenes

    Each chapter defines its own bounds, color wash, light, entry position and transition. Layers bake on first entry and remain cached instead of repeating that work every frame.

  2. 02

    Make the knights share the frame

    Drop-in local co-op uses a camera that fits both characters. Movement and combat operate across a shallow depth band, so circling and spacing can matter inside the painted world.

  3. 03

    Use rest as a transition

    The campfire ritual connects chapter changes, saving and a second player’s arrival. Rest, revival and quieting share a related visual vocabulary.

03 / the skills in the work

what this helped me practice.

The project develops layered environment painting, procedural character animation and contextual camera design. It also connects co-op input, combat timing and chapter persistence through a small set of shared rituals.

  • Canvas 2D
  • TypeScript
  • Procedural animation
  • Layered scene composition
  • Local co-op

a note on the process.

Reusing a gesture can give separate systems a common feeling. The campfire is useful because it does narrative, progression and co-op work in the same place.
